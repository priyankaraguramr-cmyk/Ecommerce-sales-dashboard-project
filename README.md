# Ecommerce-sales-dashboard-project
Retail Sales Dashboard Analysis Report
Project Objective: To analyze retail sales transactions and build an interactive Excel
dashboard that provides insights into revenue performance, product performance, store
performance, regional contribution, category-wise sales, and sales trends over time.

Dataset Description:
The dataset contains retail sales transaction records along with product, customer, and
store information. The analysis was performed using Excel Pivot Tables, Pivot Charts,
XLOOKUP functions, KPIs, and interactive dashboard components.

Column Description
Column Name Description:
Sales_ID Unique sales transaction identifier
Order_Date Date of transaction
Customer_ID Unique customer identifier
Product_ID Unique product identifier
Store_ID Unique store identifier
Quantity Quantity sold
Unit_Price Price per unit
Discount Discount applied
Payment_Type Payment method used
Total_Amount Final transaction value
Product_Name Product description added using XLOOKUP
Category Product category added using XLOOKUP
Region Store region added using XLOOKUP

Data Cleaning & Transformation:
• Validated data consistency across Product, Store, and Sales tables.
• Corrected Product ID mismatches.
• Used XLOOKUP to enrich Sales_Fact with Product_Name, Category, and Region.
• Verified lookup results and removed #N/A issues.
• Structured the dataset into an Excel table for Pivot analysis.
Visualization and Insights Arrived with Dashboard

Descriptive Analysis:
• Total Revenue: 2,170,907
• Total Orders: 2,000
• Total Products: 100
• Total Stores: 20
• Sports and Electronics generated the highest revenue among categories.

Diagnostic Analysis:
• Region-wise analysis identified North, South, East, and West contributions.
• Store-level analysis highlighted top-performing stores.
• Product-level analysis identified high-revenue products.

Predictive Analysis:
• Historical sales trends indicate consistent demand across major categories.
• Revenue concentration in selected categories suggests future growth opportunities.
• High-performing regions can be targeted for expansion.

Prescriptive Analysis:
• Increase inventory for top-performing products.
• Strengthen marketing campaigns in high-revenue regions.
• Improve promotions for low-performing categories.
• Monitor daily sales trends for better operational planning.

Conclusion:
The Retail Sales Dashboard successfully transformed raw transactional data into
meaningful business insights. The dashboard provides a comprehensive view of revenue
performance across products, stores, regions, and categories. Interactive filters and
visualizations enable users to monitor performance, identify trends, and support datadriven decision making.
